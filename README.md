# Iran Economic Dashboard — Prototype

این پروژه یک نمونه ساده از داشبورد وب با Python و Streamlit است.

## اجرا

در Terminal / Command Prompt وارد پوشه پروژه شوید و بزنید:

```bash
pip install -r requirements.txt
streamlit run app.py
```

بعد مرورگر باز می‌شود و داشبورد را نشان می‌دهد.

تمام داده‌ها ساختگی هستند و فقط برای نمایش ساختار پروژه‌اند.
